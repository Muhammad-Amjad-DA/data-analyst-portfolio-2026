# Data Analyst Projects

SQL · Excel · Power BI · Tableau · Python (pandas)

A set of end-to-end data analysis projects. Each one takes a raw dataset through data cleaning, analysis, a dashboard, and a set of business recommendations.

## Projects

| # | Project | Question | Tools | Result |
|---|---------|----------|-------|--------|
| 1 | [Retail Sales & Profitability Analysis](01-retail-sales-profitability) | Which products/regions are driving profit vs. just revenue? | SQL, Excel, Power BI | Flagged product lines with high revenue but negative margin |
| 2 | [Customer Churn Analysis](02-customer-churn-analysis) | Which customers are about to leave, and why? | Python (pandas), SQL, Tableau | Identified top churn drivers and the at-risk segment |
| 3 | [SaaS Signup Funnel & A/B Test Analysis](03-saas-funnel-ab-testing) | Where do users drop off, and did the pricing test work? | SQL, Python (stats), Power BI | Quantified funnel drop-off stage and test significance |
| 4 | [Operations & On-Time Delivery Analytics](04-operations-analytics) | Which warehouses/routes are missing SLAs and why? | SQL, Excel | Isolated the operational driver behind late deliveries |

## Skills

- **SQL** — joins, CTEs, CASE statements, subqueries, window functions (RANK, LAG, running totals), aggregations, data-quality checks
- **Excel** — PivotTables & PivotCharts, XLOOKUP, SUMIFS/COUNTIFS, Power Query, KPI dashboards with slicers
- **Power BI / Tableau** — KPI cards, DAX measures, trend lines, filters, drill-downs, star-schema data modeling
- **Python / pandas** — data cleaning, merging, groupby aggregation, visualization (matplotlib/seaborn), statistics (t-tests, A/B significance testing)

## Structure

Each project folder contains a README with the business context, the SQL/Python scripts, sample data, and a dashboard build spec (with screenshots once built locally).
